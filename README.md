# Master Smith
###### This mod is an equipment upgrade mod created for Bannerlord.

### Description
**Master Smith** is an equipment upgrade mod that you can activate by pressing CTRL + H at 9 specific Vanilla city blacksmiths. Equipment includes; Weapons, Armor, Horse Armor and Banners. Features and usage instructions are below.

<details>
  <summary>9 Specific Cities and Cultures</summary>
  This setting can be disabled in the mod settings.<br>
  Quyaz - Aserai<br>
  Marunath - Battania<br>
  Zeonica - Empire<br>
  Lycaron - Empire<br>
  Diathma - Empire<br>
  Makeb - Khuzait<br>
  Thronderlag - Nord<br>
  Varcheg - Sturgia<br>
  Galend - Vlandia
</details>

### Installation
1. Download the mod here or from [NexusMods](https://www.nexusmods.com/mountandblade2bannerlord/mods/11682).
2. Go to your game's Mount & Blade II Bannerlord\Modules folder.
3. Put the folder in the ZIP here.
4. Open Launcher and go to **Mods** section
5. Click on the mode and enter the game.

### Requirements
[Bannerlord Harmony](https://www.nexusmods.com/mountandblade2bannerlord/mods/11597)<br>
[Mod Configuration Menu](https://www.nexusmods.com/mountandblade2bannerlord/mods/612)

### Features
- You can upgrade any equipment you want to the maximum quality it supports through 9 specific cities (changeable).
- The order will be delivered automatically if you are in the city where you placed the order. It will send a notification if you are not in the city and it will be delivered automatically when you enter that city.
- In order to make a piece of equipment legendary, you must visit cities that are directly proportional to its culture.
- Before/After statistics, order details can be viewed before ordering.
- The order placed can be canceled in the same city by selecting it from the same menu.
- Thanks to the Rush Order mechanic, you can cut the order time in half by paying 50% more money.

---

### Compatibility
**It should be compatible with any map mod** when the "Use Specific Smith Cities" setting is turned off in the mod settings.

---

### Usage
1. Enter one of 9 specific cities.
2. Enter the blacksmith.
3. Press CTRL + H.
4. Do whatever you want from the order screen.
